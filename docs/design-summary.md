# Design summary

## Product promise

Turn a spoken request into a concise, reviewable action plan while minimizing driver interaction.

## MVP flow

1. Capture a request.
2. Ask GPT-5.6 for a schema-constrained plan.
3. Present a short summary and proposed actions.
4. Require confirmation for state changes.
5. Execute approved actions locally.

## Explicit exclusions

Vehicle control, CAN/OBD access, continuous listening, production Android Auto distribution, messaging integrations, and cloud synchronization.
